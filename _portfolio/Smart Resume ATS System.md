## Objective

An Applicant Tracking System (ATS) style tool that uses Google's LLMs to read a resume and a job description, then produces a clear summary and a skill-gap analysis - the kind of first-pass screening a recruiter or candidate can use in seconds instead of minutes.

## Features

<u><b>Resume analysis</b></u> :
Upload a PDF resume and get a concise, structured summary highlighting key skills, experience, education, and achievements, generated by Google's GenAI models.

<u><b>Skill-gap analysis</b></u> :
Paste in a target job description and the system compares it against the resume to identify missing or underdeveloped skills, with concrete recommendations on how to close the gap - useful both for candidates tailoring a resume and recruiters screening applicants.

## Implementation

The app is a Streamlit front-end (`app.py`) backed by a dedicated `prompts.py` module that defines the LLM prompts for resume summarization vs. skill-gap comparison, and `utils.py` for PDF parsing and file handling. Dependencies are managed with PDM, and the Google GenAI API key is supplied via environment variables so it can be run entirely locally.
